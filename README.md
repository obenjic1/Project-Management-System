# Project Management System

A full-featured project management platform that helps teams track work, communicate, and handle payments in one place.

## Features
- Project and task management
- Real-time chat / messaging
- Issue reporting and tracking
- Payment integration
- User roles and collaboration tools

## Tech Stack
- **Backend:** Java, Spring Boot
- **Frontend:** (see `Front-end` folder)
- **Build:** Maven

## Getting Started
1. Clone the repository
2. Configure your database connection in `application.properties` / `application.yml`
3. Run with Maven: `./mvnw spring-boot:run`

## Project Structure
```
├── Front-end/          # Frontend application
├── src/                # Spring Boot source code
├── pom.xml             # Maven dependencies
└── README.md
```
